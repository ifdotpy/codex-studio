- `errors/ux-request-recovery-browser.spec.mjs`: select and inspect project defaults through the AccountTiles group and its account button, including disabled and selected values while a request is unresolved. Class 2, `f4f176f1` replaced the old account select with account tiles.

## Checkpoint 4 sync and transcript-windowing repairs

- `sync/entity-commit-propagation-browser.spec.mjs`: old expectation relied on pull polling; now verifies committed entity rows through stream frames, persisted projections, and the full 30-token batch. Class 1 fixture/transport update; 3/3 solo after correction.
- `sync/snapshot-order-ui.spec.mjs`: old fixture did not tie its mutation to a real committed sequence; now asserts the mutation's committed worker sequence reaches the pull and UI without allowing delayed credentials to overwrite newer replicated state. Class 1; 3/3 solo.
- `sync/sync-stream-measure.spec.mjs`: old measurement could begin before the stream's initial baseline and could measure invalidation without pull persistence; now synchronizes on the live baseline and measures delivered writes through persistence. Class 1/3; 3/3 solo, median write-to-render 133–136 ms, idle pull count 0.
- `sync/sync-cross-tab-browser.spec.mjs`: corrected versioned fixture baseline and retained exact 7/8 callback/read invariants; deterministic takeover now asserts one active server stream and its exact local-plus-peer resource union, while logging observed opens and queries. The intermittent resumed-owner two-stream check is isolated in a separate unconditional `test.fixme(true, reason)` test with the original 1,500 ms wait and assertion. Class 1 fixture plus confirmed intermittent product defect; 10 marker-free repeats of the combined test found 2 duplicate-owner failures, and 1 redundant identical takeover reopen.
- `sync/sync-cross-tab-browser.spec.mjs` takeover query accounting: old test treated request counts as a fixed setup detail; new behavior checks the final union and one active stream, and logs every open/close/query. In 9/10 audits there was one union request; 1/10 had an identical replacement after 13 ms. This measured re-open remains in `KNOWN-FAILURES.md` with the owner-resume defect.
- `conversation/conversation-motion-ui.spec.mjs`: old test emitted before the transcript stream was connected and targeted a virtualized row; now waits for the stream and reveals the target row. Class 1/3.
- `performance/draft-render-performance-browser.spec.mjs`: old test used fixed optimizer delays; now waits for the required draft state and render frames. Class 1/3.
- `performance/large-history-ui.spec.mjs`: old test intercepted sync with an invalid 404; now serves the valid sync fixture and reveals the target historical row. Class 1/3.
- `performance/repeated-read-counts-browser.spec.mjs`: old menu locator targeted a stale execution-menu selector; now scopes the current Subagent defaults dialog and model picker. Class 2.
- `performance/sidebar-incremental-render-browser.spec.mjs`: old assertions counted conversions without enforcing snapshot reuse; now asserts zero conversions for immutable retained snapshots and exactly one render after the next update. Class 2, behavior introduced by `5c0df4a1`.
- `performance/transcript-render-performance-browser.spec.mjs`: old harness omitted the scroll container required to activate transcript windowing; now supplies it, reveals and scrolls to the measured row, and waits for mounted rows before timing. Class 1 harness plus class 2 windowing behavior introduced by `7c4e18ea`.
- `performance/ui-responsiveness-browser.spec.mjs`: old test measured a virtualized, unmounted result row; now reveals the target before measuring. Class 2, windowing introduced by `7c4e18ea`.
