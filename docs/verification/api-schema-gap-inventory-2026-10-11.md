# API schema gap inventory — 2026-10-11

This inventory records route declarations and gaps established before schema edits. It is conservative: `handler comparison open` means the route and OpenAPI operation were introspected, but the handler was not read, so completeness is not claimed. The introspection walked `FastAPI.routes` recursively through deferred `_IncludedRouter.original_router.routes` and compared effective methods and paths with `openapi_document()`.

Route table: 163 method/path entries (156 under `/api/`), including 14 hidden entries. The plan counted 150 decorators; this table counts effective method/path entries and includes FastAPI documentation, static app routes, and hidden fallback routes.
