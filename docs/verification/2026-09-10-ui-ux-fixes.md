**Дополнительные проверки**

- Общая сборка включает TypeScript и оба пакета Vite.
- Серверные проверки: история и ветки (13), Workspace (34), начало сообщения (16), подготовка и steer (14).
- Независимый обзор проверяет поиск, перенос аккаунта и сохранение предыдущих сообщений в ветке.
- Проверены обе темы при ширине 320, 390 и 1440 px.
- Проверены длинные названия при ширине 390, 1024, 1280 и 1440 px.
- Новая мобильная ветка сохраняет выбор до получения нового списка чатов. Исходный черновик сохраняется.
- Проверены мобильные окна при уменьшении доступной высоты из-за клавиатуры.

**Пределы проверки**

- Живой backend, агенты, мониторы и терминалы пользователя не перезапускались.
- Реальные запросы модели, микрофон и платное восстановление лимита не использовались.
- Поддержка диктовки в браузере зависит от наличия SpeechRecognition.
- Проверки native API используют фикстуры. Они не подтверждают работу голосового сервиса или конкретного аккаунта.
- Новые серверные и native-возможности требуют загрузки обновлённых процессов после завершения активной работы.

**Повторная проверка**

`npm --prefix web run test:ux-audit` запускает сборку и специализированные проверки этих изменений.
Существующие проверки чата, аккаунтов, сообщений, проектов и терминала выполняются отдельно.
