# Remaining turn-path wiring

Batch A registers the accepted subsystems on `integration/rust-turn-path`.
Their isolated consumers and HTTP contracts are testable together; production
account-worker wiring remains a separate change. The only worker-file edit here
exposes `account_worker::history::message` to notification handling.

| Subsystem (accepted source)                   | Integrator calls still required                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Budget (`8b96e417`)                           | Inside the owning transaction, call `budget_service::admission(tx, agent_id, histories, now)` before consuming events, and `defer_wait` / `claim_wait` for budget wait transitions. Notification usage calls `budget_service::capture(tx, agent, params, at, CaptureSource::Live, now)`; historical capture supplies `CaptureSource::History`. Read histories outside the transaction.                                                                                                                                                |
| Radio (`7ddf7117`)                            | Build `RadioAuthorizationSnapshot::from_records(&records)`, then call `authorize_turn(event_id)` at admission. Persist an allowed `RadioThreadBinding` with the owning event transaction. Queue construction, floor selection, answer routing and turn completion remain separate stateful owners; this authorization port does not implement them.                                                                                                                                                                                   |
| Claude (`cc2828ee`)                           | Construct `claude_controls::service::Controls` with the retained `ControlSession` and storage adapters; route controls through `execute` / `read_or_stop`. Capture frozen input with `claude_input_recovery::capture_input`; use the transactional `store::{recover_rejected_start,retry_batch,retry_input,resume_held_retry,retire_stopped_retry}` calls at their lifecycle boundaries. Sign-in routes and their retained `LoginService` are already registered; retained-session controls keep their named refusal until connected. |
| Voice (`4991e2b0`)                            | Implement `VoiceProviderPort::{prepare,request}` using the generic account session and install it with `HttpState::with_voice_provider`. Retain one `VoiceCallbackActor` per account session and route realtime notifications and disconnects through `handle_notification` / `handle_disconnect`. Preserve request certainty and commit durable receipts before reporting success.                                                                                                                                                   |
| Turn recovery (`3d9c23ce`)                    | Supply `RecoveryReader`, scoped `RecoveryEffects` via `RecoveryStore` and `CompletionWriter`, then call `recovery::{recover_turn,recover_connection}`. Supply `TaskRecoveryEffects` via `TaskRecoveryStore` / `TaskCompletionWriter` to `task_recovery::recover_task`. Recheck ownership and receipts in the effect transaction; never resend unknown native input. The connection-recovery route retains `account-worker/recovery-history`.                                                                                          |
| Supervisor (`d6687767`, including `6b9b1d2b`) | Launch `codex-process-supervisor` for the owned state root (`supervisor_daemon::serve`), then connect the existing `SupervisorClient` / `ProviderTaskFactory` seam. Retain exact request identities, commit effects before ACK and preserve Unknown receipts. Startup ownership belongs to later server wiring.                                                                                                                                                                                                                       |
| Notification kinds (`bd9025a5`)               | Replace the unavailable adapter with `dispatch_notification_with_effects(..., &effects)`. Implement `NotificationEffects::capture_usage` using `budget_service::capture(..., CaptureSource::Live, ...)`, and `capture_move_cache` using the agent-move owner's `agent_move::capture_cache`. Both effects and the notification receipt share one transaction; no provider or filesystem work inside it. Other missing services continue to refuse by name.                                                                             |
| Catalog reads (`5369c49f`)                    | Server construction must call `HttpState::with_tool_catalog(PreparationResources.catalog)`. The shared `provider_exchange` admission bound and `thread_prepare::full_tool_catalog` accessor are included. Capabilities retain the tool-catalog dependency until this injection is supplied.                                                                                                                                                                                                                                           |
